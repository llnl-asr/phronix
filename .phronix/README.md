# What earlier runs learned

Everything in this directory was produced by a run, not shipped with the framework: skills written or amended while solving tasks, research records, memory, capabilities and verifiers.

It is committed on purpose. Research is the expensive part, and the point of keeping it is not paying for it twice.

A run seeds itself from here by default. `--fresh` ignores all of it and starts from the bundled framework alone, which is how an approach gets evaluated cleanly — a fresh run still syncs what IT finds back into here when it ends.

`research/sessions/` is the exception: per-run working state, git-ignored, folded into `research/` as each task finishes.
