# Lessons: system_tuolumne_spindle

- [L-18c9c1ce] SPINDLE_FLUXOPT set inside the launched job script had no effect -> The flux shell plugin reads SPINDLE_FLUXOPT at job-shell init, before the launched script starts. -> Export SPINDLE_FLUXOPT in the shell before flux run / flux proxy. (2026-07-22)
- [L-5d4dc99b] SPINDLE_FLUXOPT=high gave ~167s import-to-first-step vs ~98s with disable (PECAN, 4N x 4 GPU, single replicate) -> Opposite of the hypothesised win; single replicate on a shared system, no medium baseline; Spindle's O(ranks) vs O(files) savings may not dominate at this scale. -> Do not adopt high on one replicate; run >= 5 replicates of disable/medium/high on a dedicated allocation. (2026-07-22)
- [L-cba3ea40] 5-replicate A/B, PECAN 4N x 16 ranks, --exclusive: disable 47.3s (sd 14.7), medium 153.5s (sd 17.8), high 146.4s (sd 2.6) -> Spindle at either level adds ~100s of import-phase latency at 16-64 ranks; medium and high are statistically indistinguishable (high more consistent). -> Use SPINDLE_FLUXOPT=disable for PECAN-style Python/PyTorch DL jobs at 4-8 nodes; crossover rank count is an open question. (2026-07-22)
- [L-d30d4f2d] -o spindle.level=high accepted but its effect unverifiable -> A flux run --output=<file> capture quirk left output empty for both the flag job and a plain baseline. -> Use the exported env var for measured A/Bs until the flag is verified. (2026-07-22)
