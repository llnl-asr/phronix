# Lessons: phronix_self_learning

- [L-81926a74] Recording the fix without the symptom -> An entry that says only "add `-fcommon` to CFLAGS" is unreachable: nobody searching for the linker error they are staring at will find it. Always lead with the error text as it actually appears. -> follow phronix-self-learning P1 (Corner cases) (2026-09-15, dftracer-agents phronix-self-learning/LESSONS.md P1)
- [L-3e3e80e3] Filing a site-specific quirk in a generic subject -> A quirk that is true only on one machine, recorded in a generic skill, misleads everyone else — and is trusted, because it is in the authoritative place. Scope it to the specific subject and link from the generic one. -> follow phronix-self-learning P2 (Corner cases) (2026-09-15, dftracer-agents phronix-self-learning/LESSONS.md P2)
- [L-35713412] Widening a skill instead of creating one -> When a lesson does not fit the subject, the tempting move is to widen the subject. Do not: a skill that covers two things becomes findable for neither. Create the second subject and link it — see [[phronix-skill-authoring#R1]]. -> follow phronix-self-learning P3 (Corner cases) (2026-09-15, dftracer-agents phronix-self-learning/LESSONS.md P3)
