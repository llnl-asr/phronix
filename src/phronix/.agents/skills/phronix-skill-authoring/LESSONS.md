# Lessons — phronix-skill-authoring

Pitfalls and dated lessons for the **authoring and growing skill files** subject. Retrieved by *memory*
search (`context_memory`), not by skill search: "how do I do this" and "what went
wrong last time" are different questions, and keeping them in one file makes every
retrieval of either drag in the other.

## Pitfalls

### P1 — A skill that is a session transcript

Nobody reads a narrative of what one session did. Extract the rule and the
instruction; the story belongs, at most, in a dated lesson.

### P2 — A description that does not describe

The description is the primary retrieval signal. A vague one makes the skill
unfindable, which is operationally identical to not having written it.

### P3 — Copying a block from another subject instead of linking

The copy and the original then diverge. Whichever one the next agent finds, it has
no way to know the other exists or which is current.
